UninstallAny

使用普通用户账户启动桌面应用。
Windows 解压后打开 UninstallAny.exe。
macOS 解压后打开 UninstallAny.app。
Linux 解压后从图形文件管理器启动 uninstallany。

程序从本机读取已安装应用。
先审阅官方卸载操作，再审阅残留清单并确认选择。
只在隔离区中还原本工具备份的对象。
官方卸载器和系统包管理器由各自的发布方和系统维护。

Start the desktop application using a regular user account.
On Windows, extract the archive and open UninstallAny.exe.
On macOS, extract the archive and open UninstallAny.app.
On Linux, extract the archive and start uninstallany from your file manager.

Review the official uninstall action and then review any selected leftovers.
The quarantine can restore objects saved by UninstallAny.
